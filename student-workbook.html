Lesson 1 Ask before changing

Useful questions and a ticket process reference

Fictional report: "The classroom display does not work." The teacher needs to show a lesson and use touch. The picture is visible, but touch does not respond in the tested program.

The eight ticket stages

Classroom ticket process reference
StageWhat it means
AwareLearn about the issue.
IdentifiedConfirm symptoms; the cause may still be unknown.
ContextedGather the context needed for this issue.
EquippedHave the required resources.
Fix StartedBegin the approved fixing work.
FixedFix the issue and reasonably check for other problems.
DeliveredReturn or explain the solution and confirm the customer's task.
DoneComplete the ticket.

These are classroom process terms, not eight website buttons. The site uses three tabs. Confirming a symptom does not prove which part is faulty.

Lesson 1 Request and clues

INC-101 The Blank Monitor or the case your teacher assigns

Open www.colelearninglabs.com. Choose a lab and read its original task. Use the numbered tabs on the same page; you can return to an earlier tab at any time.

1. Request & clues

Read the request. In Talk with the requester, write Your question and choose Ask the requester. Ask a follow-up in your own words. The replies use fictional case facts on this device; they may ask you to clarify. Tap at least two clues to add them to your report.

Current interface note: the conversation is headed Talk with the requester’s name and uses Send message. Case replies remain local; optional extra AI replies are not case evidence. Choose clues with the keyboard or pointer. The numbered steps may open separate views while retaining your current work.

Put your first idea in the website field with the same label. In an incomplete request, clarify the missing detail shown on screen before finishing. A reasonable first idea can change after testing.

Paper alternative: ask your teacher for fictional observations and a test result. Record only the information you receive; do not invent a successful repair.

2. Workbench & test

Use the pictured virtual equipment or labeled controls. Read the safety prompts and current state. Make one change at a time. Save or apply edited settings where shown. Run hypothesis test checks the current setup; read what it reports.

Optional experiment record

Write I predict, then choose Start experiment · record Before before changing the setup. Make one virtual change and write I changed. Choose Run test & capture After. Compare Before and After; write I observed and This supports or changes my idea because. Choose Save this attempt.

Use the blank record on page 5 for your assigned case. A failed test is useful evidence. A passing simulation check is technical feedback; your teacher reviews your explanation.

Lesson 2 Check and explain

Verification and a truthful report or handoff

3. Check & explain

Return to the original task. In hardware labs, use Open lesson file when the simulated system is ready. Choose Check the original task. Complete What did you change, and what did the test show? and Does the evidence support your hypothesis? Why?

Review and export

Use My report or Preview my report to review work at any stage. Finish investigation & open report completes the workflow only when the on-screen requirements are met. An honest in-progress report is useful for a handoff.

The report includes ORIGINAL TASK, EVIDENCE, QUESTIONS I ASKED, WORKING HYPOTHESIS, TEST NOTES, EXPERIMENT RECORD, ACTION LOG, and REFLECTION. Review it for private information before exporting.

Follow your teacher's approved route. If given a teacher public key, verify its fingerprint through the trusted school channel before Encrypt this report. Otherwise, open Plain-text export and export only with approval using Copy plain-text report or Download plain text. Exporting does not submit work.

Private practice stays on this page unless you export or explicitly enable device saving. Device-saved work is unencrypted. Export before closing or reloading the page. The numbered lab tabs keep current work in place. Clear saved work before sharing the browser profile.

The preceding saving controls refer to the investigation site. This standalone workbook page has no device-saving or submission feature.
