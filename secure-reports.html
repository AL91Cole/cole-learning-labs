What this protects
Reports use a fresh AES-256-GCM key and nonce, with the report key protected by RSA-OAEP (SHA-256, 3072 bits). The private key file is encrypted using AES-256-GCM and a PBKDF2-SHA-256 passphrase-derived key with 600,000 iterations. Your alias and report are encrypted together. Processing uses the browser’s Web Crypto API.
Encryption protects attachment contents from someone without the private key and passphrase. It does not conceal Classroom account identities, class rosters, submission activity, attachment size, or a compromised device. Public keys are not proof of identity; trusted fingerprint checks matter. A code and encrypted report do not verify the author; use your school’s approved assignment access controls. This tool is not an independently audited encryption product, and it does not certify legal compliance. Use district-approved systems and policies.
Nothing entered here is intentionally stored in local storage, session storage, analytics, or an application database. This page makes no application requests with your report or keys. Normal website delivery still uses hosting and network services. Read the school IT review.
