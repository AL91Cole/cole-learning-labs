# Third-party software

The current public site uses browser-native HTML, CSS and original SVG equipment diagrams. No third-party 3D engine, graphics CDN, remote model or package is required at runtime. The ordinary build and CI do not install npm packages.

The classic visual release removes the Babylon.js bundle, scenes, license/notice assets and engine build scripts from the current source and reviewed public manifest. The prior engine release remains available in Git history with its licensing and supply-chain documentation. The ignored local graphics dependency cache is not published.

Learning models, interactions, reports and privacy controls remain authored in this repository. Removing the renderer does not change the production classroom privacy lock or enable any provider connection.
