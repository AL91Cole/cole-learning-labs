# First complete classroom course

Technology, AI & Cybersecurity Foundations is the first nine-week Cole Learning Labs course for grades 7–8: 45 lessons of 40 minutes each. It is an authored teacher-review edition, with school-device and classroom-pilot acceptance still pending.

`/courses` lists the published course and says more courses will be added. It does not advertise unavailable enrollments, dates, accounts or products. `/courses/foundations` contains the course map, teacher preparation, assessment, privacy guidance and student downloads. Forty-five stable day URLs provide full teaching sequences, student handouts, linked interactive simulations, concrete paper/projected alternatives, exit tickets and support/challenge options. The project and selected standards crosswalk have their own pages.

Public pages contain instructional examples and assessment criteria. Confidential teacher keys remain in the private package created in the prior task. No public page links to the private Drive folder or offers it as a secure teacher portal. Public student Word and PDF downloads are separately reviewed and pinned. No original archives, teacher-guide files or student records are copied into the repository.

Each Share to Classroom link contains only the generic public lesson URL with its handout anchor. Google handles sign-in and class selection. The site does not receive school credentials, a roster, submissions or grades. Teachers attach a school-owned handout copy separately; students submit manually through Classroom. Existing closed collection gates, API routes and hosting bindings are unchanged.

`courses/foundations/course-data.mjs` holds the reviewed public authoring. The build parses its JSON literals and generates the static pages; the data source is not a hosted endpoint. To revise this course, edit its public data, review student downloads if changed, and run the focused course tests plus the normal check, test and build commands. Add future course entries to the catalog only when their content is ready; planned courses need no invented dates.

Validation covers all 45 days, exact daily timing, source routes, safe sharing URLs, internal links, download hashes, the build and preview allowlists, metadata, code indentation and teacher-key exclusion. The coding examples were also checked in the project's local interpreter during package authoring. The NYSED codes were verified from official indexed excerpts; direct PDF retrieval was unavailable. The author-created crosswalk identifies supporting work and limits, including introductory control-structure practice. It does not claim full grade-band coverage or NYSED endorsement.

A manual Chromium review covered the catalog, course overview and day 38 student handout, including 200% text zoom with normal page reflow. That review does not establish school-managed device or assistive-technology acceptance. The native print dialog was unavailable in that browser session; print CSS and the downloadable PDF companions were checked separately.
