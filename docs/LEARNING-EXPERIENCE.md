# Learning experience verification

The shared activity guide gives a concrete first move and a focus button that
locates the relevant control. A closed three-step explanation covers changing,
testing and retrying. The focus button does not click, submit, run a simulation,
earn progress or supply an answer. Its targets are an authored local allowlist.

This guidance covers all 25 arcade games, 12 eight-lesson coding paths, 15
elementary activities, five foundation courses and Inbox Defender. All 42
investigations also show a next move based on the existing intake, experiment,
freshness and explanation requirements. Workbenches and studios include first
actions. The catalog offers a starting-point chooser.

Arcade games give specific feedback for setup changes and failed checks. The
rover replays the computed route with cargo counts, pause, replay and manual
steps. Playback preserves the interactive controls and cancels on edits, room
changes, reset and disposal; reduced-motion runs show the result immediately.
Packet routes highlight connected tiles and animate along the computed path.

Rover palettes introduce repeats in Loop Lagoon and conditions in Branch Bridge.
The other rover missions use four basic directions; model checks enforce the
same palettes. Arcade grade filters combine with topic filters. Success links
recommend another available game in the exact grade band. Elementary completion
offers another activity in the same band; foundation courses lead to their
investigation. Coding paths explain wrong results and allow a fresh try of the
current successful lesson without restarting the path or skipping a check.

## Validation

- Full application suite: 1,778 passed, two existing Windows link-related skips,
  zero failures. Syntax check: 100 application/server modules. Public build:
  28 reviewed files; no new dependency or engine.
- All 25 arcade models retain a failed start, a playable solution and reset.
  New regressions cover command palettes, actual replay frames, focus/control
  preservation, cancellation, reduced motion, safe guide targets, all 58 guided
  activity pages, grade/topic combinations and coding feedback/retry gates.
- Existing all-42 investigation navigation, draft preservation, notebook and
  test-freshness suites pass with the guide using the real progress state.
- Browser QA includes desktop Chrome and 390 × 844: guide focus, a completed
  rover route with all cargo, replay/pause, combined grade/topic filters,
  wrong/correct coding feedback, lesson retry, and an offline investigation
  prompt advancing from question to clues to symptoms and then the workbench.
  Elementary completion now renders a working link in the same age band; all
  15 completed states are checked for a real target and unevaluated template
  text. Packet Post's successful route highlights and pulses its seven actual
  path tiles. No horizontal overflow appeared in these mobile checks.

The change adds no collection or persistence. Existing school privacy,
authentication, owner-build and assessment boundaries remain separate. Automated
coverage and sampled browser checks cannot establish how every student will
experience the activities; classroom observation remains useful for the next
round of improvements.
